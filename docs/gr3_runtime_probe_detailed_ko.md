# Grandia III 음성 이벤트 상세 추출기

이 도구는 실행 중인 PCSX2의 EE RAM을 PINE 소켓으로 **읽기만** 한다. 게임 메모리를
수정하거나 플레이 전 구간을 자동 기록하지 않는다. 대사가 들리는 순간 사용자가
버튼을 눌러 한 장면의 상세 스냅샷을 고정하는 방식이다.

## 실행

macOS에서는 다음 앱을 더블클릭한다.

```text
tools/GR3 Runtime Probe.app
```

또는 다음 실행 파일을 연다.

```text
tools/launch_gr3_runtime_probe.command
```

PCSX2에서 PINE가 활성화되고 게임 VM이 실행 중이어야 한다.

## 권장 사용 순서

1. 이벤트 직전에 게임 내 메모리카드에 저장한다.
2. PCSX2 상태저장은 사람 대사가 실제로 들리는 도중 만든다.
3. 추출기의 `장면 설명`과 `상태저장 슬롯`을 입력한다.
4. 같은 대사가 들리는 순간 `지금 읽고 고정`을 누른다.
5. `상세 JSON 저장…`으로 파일을 저장하거나 `상세 조사 요청 복사`를 누른다.
6. 이벤트 도중 음성이 바뀌면 값이 바뀐 시점마다 한 번씩 다시 고정한다.

자동 갱신은 화면 값만 갱신하며 로그나 JSON 파일을 자동 생성하지 않는다. 수동으로
고정한 뒤 저장해야 해당 순간이 조사 자료로 남는다.

## 상세판이 기록하는 값

- 현재 필드/이벤트 리소스 표시와 원본 64바이트
- `0x001FEA20` 표시 sample ID, 매핑된 GR3 stream, 원본 32바이트
- 표시 sample 진행 틱과 초 환산값
- request slot 0/1의 state, requested, secondary, resolved sample ID
- 각 request slot의 진행 틱, 초 환산값, 전체 원본 바이트
- `0x001E8B40` 자막 타이머 stream key와 진행 틱
- 실제 음성 후보로 고른 request slot과 선택 근거
- 기존 rendered-event workqueue의 event ID, 장면, 예상 리소스, 런타임 상태
- 캡처 시각, 장면 메모, 상태저장 슬롯

진행 시간의 초 환산은 현재 프로젝트의 60 ticks/sec 기준 보조값이다. 최종 자막
싱크는 상태저장 SPU2와 원본 음원을 다시 대조해 확정한다.

## 안전 경계

- PINE `Read8` 명령만 사용한다.
- PCSX2 프로세스에 직접 attach하지 않는다.
- 게임 메모리와 상태저장을 수정하지 않는다.
- JSON 저장은 사용자가 버튼을 눌렀을 때만 수행한다.
- 추출 결과만으로 신규 이벤트를 확정하거나 ISO를 만들지 않는다.
