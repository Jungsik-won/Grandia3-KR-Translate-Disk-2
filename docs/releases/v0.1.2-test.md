# Grandia III 한국어 패치 v0.1.2-test

`v0.1.1-test` 이후의 누적 시험 배포판이다. 원본 ISO에서 xdelta를 재적용한 결과와
ISO 역추출 결과를 byte-exact로 검증했지만, 실제 게임 구동(runtime) 테스트는 아직 대기 중이다.

## 추가 반영 내용

- 전투 작전·방어 글리프 수정
- 첫 전투 튜토리얼 도움말 인덱스 복구(EN074C 원본 유지)
- 몬스터명 자연화 및 행동 주소 보존
- 0x63 slot0 자막 트리거 수정 및 0x62 안전 제외
- GRM13 자막 30큐 발화 단위 재분할
- 기존 누적 한국어 텍스트, 하드서브 영상, 0x9B 자막, 결과 화면 텍스처 반영분 유지

## 배포 파일

원본 게임 ISO, 패치된 ISO, 추출 게임 자산은 배포하지 않는다. GitHub Release에는 다음 6개 파일만
올린다.

- `Grandia3_KR_Disc1_Korean_8ab14274_full.xdelta`
- `apply_in_place_ko.sh`
- `apply_in_place_ko.ps1`
- `README_ko.md` (한국어 안내서)
- `release-manifest.json`
- `SHA256SUMS.txt`

## 필수 원본 및 결과

사용자는 합법적으로 보유한 정확한 일본판 Disc 1 ISO가 필요하다.

- 원본 크기: `4,598,890,496 bytes`
- 원본 SHA-256: `c588a7dada3bf7175bfe97b238b0ab4c77df6401a58d766829aec9d92f3596e8`
- 패치 크기: `2,127,140,711 bytes`
- 패치 SHA-256: `d20350bfa6eb169c08bad40eb7a86952c6f595e9030b36b630979ac6e1277d34`
- 결과 ISO 크기: `5,757,884,416 bytes`
- 결과 ISO SHA-256: `8ab14274af27ed97b51f78775682e27be284489b5071f571d40b374ca5eb122d`

## 검증 상태

- xdelta3 3.2.0 decode 완료
- 복원 ISO SHA-256 일치 및 `cmp` byte-exact 통과
- ISO9660/UDF 역추출 결과 모두 byte-exact
- relocation count: `0`
- runtime test: pending

## 저작권 및 면책

Grandia III 관련 권리는 각 권리자에게 있다. 이 프로젝트는 비공식 팬 번역·연구 프로젝트이며
권리자와 제휴하거나 승인을 받은 프로젝트가 아니다. 원본 게임 ISO, 패치된 ISO, 추출된 영상·음성·
이미지·게임 리소스는 제공하지 않으며, 사용자는 자신이 합법적으로 보유한 원본에만 패치를 적용해야
한다. 개인적·비상업적 연구 목적의 배포이며, 사용으로 인한 데이터 손실이나 호환성 문제를 보증하지 않는다.
