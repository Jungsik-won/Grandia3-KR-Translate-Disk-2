# Grandia III 한국어 패치 v0.1.5-test

`v0.1.4-test`를 대체하는 누적 시험 배포판이다. 전투 중 작전 패널의 잘못된 글리프 인덱스를
해당 패널 경로에서만 직접 교정하고, 공용 UI의 색상 팔레트와 흰 외곽선·그림자 설정을 원본
동작으로 복구했다. 깨끗한 원본에서 xdelta decode, 결과 SHA-256, 전체 byte 비교, ISO9660/UDF
역추출을 검증했으며 relocation count는 `0`이다. 실제 게임 구동(runtime) 테스트는 추가 확인이
필요하다.

## 핵심 수정

- 전투 중 작전 A/B 패널에서 사용하는 6개 전술 라벨의 직접 인덱스 교정
- 전투 밖 상태창의 정상 작전 표시는 유지
- 공용 UI의 원본 색상 팔레트와 흰 외곽선·그림자 동작 복구
- v0.1.4-test까지의 한국어 텍스트, 하드서브 영상, 전투·아이템·몬스터·자막 수정 유지
- BATTLE.BIN과 FIELD.BIN만 직전 누적판에서 변경하고 나머지 1,264개 ISO 파일은 byte-exact 유지

## 적용 후 첫 실행 주의사항

상태저장 호환 문제를 피하려면 다음 순서로 실행한다.

1. PCSX2를 완전히 종료한다.
2. 새 ISO로 cold boot한다.
3. 구 ISO에서 만든 상태저장은 사용하지 않는다.
4. 일반 메모리카드 저장을 불러온다.
5. 새 ISO에서 새 상태저장을 생성한다.

## 검증 상태

- 원본 SHA-256 확인 후 xdelta3 3.2.0 decode 완료
- 복원 ISO SHA-256 일치 및 전체 byte-exact 비교 통과
- ISO9660/UDF 역추출 결과 모두 byte-exact
- 직전 누적 ISO 대비 변경 파일: `BATTLE.BIN`, `FIELD.BIN`
- ISO 내 파일 extent와 크기 유지
- relocation count: `0`
- runtime test: pending

## 저작권 및 면책

Grandia III 관련 권리는 각 권리자에게 있다. 이 프로젝트는 비공식 팬 번역·연구 프로젝트이며
권리자와 제휴하거나 승인을 받은 프로젝트가 아니다. 원본 게임 ISO, 패치된 ISO, 추출된 영상·음성·
이미지·게임 리소스는 제공하지 않으며, 사용자는 자신이 합법적으로 보유한 원본에만 패치를 적용해야
한다. 개인적·비상업적 연구 목적의 배포이며, 사용으로 인한 데이터 손실이나 호환성 문제를 보증하지 않는다.
