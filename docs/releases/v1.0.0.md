# Grandia III 한국어 패치 v1.0.0

Grandia III 일본판 Disc 1용 비공식 한국어 패치의 첫 정식 배포판입니다. 내부 `A*`/`1.6.x`
개발 빌드와 공개 `v0.1.x-test` 시험판 계열을 마치고 안정판 버전을 `v1.0.0`부터 새로
시작합니다.

## 이번 배포의 핵심 변경

- 비행기 메뉴의 고정 레이아웃과 선택 후 실행 흐름을 수정했습니다.
  - 25개 고정 한국어 슬롯을 검증했습니다.
  - `하늘을 난다`를 자연스러운 `비행하기`로 정리했습니다.
- 비행 중 표시되는 일반 목적지 안내를 유지하고, 남아 있던 특수 목적지 안내 14페이지의
  글리프·문장을 추가로 교정했습니다.
- 렌더링 이벤트 자막 누적판을 유지했습니다.
  - 66개 경로, 58페이지
  - stream `0x94`: 18큐
  - stream `0x95`: 16큐
- GRM20 하드서브를 20큐에서 21큐로 보완했습니다.
  - `00:00:29,780`–`00:00:33,120`: `참 아름답고 맑은 눈을 하고 있구나.` 복원
  - `00:00:38,160`에 시작하는 다음 자막의 기존 타이밍 유지
- 이전 누적판의 시스템·상태·아이템·전투·시나리오·카지노·선상 대화·비행·영상 자막
  수정분을 모두 유지했습니다.

## 디스크 구조

v1.0.0의 마지막 단계는 고정된 A28 부모에서 `MOVIE/GRM20.MOV` 한 파일만 동일 크기·동일
extent로 교체해 만들었습니다. 다음 항목의 재패킹·재배치 없음은 A28→v1.0.0 단계에 대한
검증 결과입니다. CLEAN→누적판 계보에는 고정 용량 planner가 안전하게 배치한 기존 relocation
135개가 포함됩니다.

- 원본과 결과 ISO 크기 동일: `4,598,890,496 bytes`
- ISO 파일 수: `1,266`
- 모든 파일의 extent와 크기 보존
- relocation: `0`
- A28 대비 raw 변경 바이트는 전부 GRM20 payload 내부
- GRM20의 원본 PS-ADPCM 음성 byte-exact 보존

## 검증

- 고정 CLEAN 원본과 고정 A28 부모의 크기·SHA-256 확인
- 최종 ISO 이중 생성 결과 byte-identical
- ISO9660/UDF 역추출과 독립 7-Zip 역추출 byte-exact
- 핵심 실행 파일·필드·전투·비행·자막 컨테이너의 A28 상속 byte-exact
- CLEAN 원본에서 xdelta decode 후 목표 SHA-256 일치
- decode 결과와 목표 ISO 전체 `cmp` 일치
- 배포 패치의 LZMA secondary header 확인
- macOS/Linux 적용 스크립트를 CLEAN 원본에 end-to-end 실행하고 목표 ISO와 일치 확인
- Windows 적용 스크립트 정적 검토 완료

누적 기능은 개발 과정에서 반복 실기 확인했습니다. 이 v1.0.0에서 마지막으로 결합된 비행 선택지,
비행 안내, GRM20 초반 자막의 한 조합은 정적·역검증을 통과했으나 장면별 최종 런타임 확인은
아직 완료되지 않았습니다.

## 첫 실행 주의사항

1. PCSX2를 완전히 종료합니다.
2. v1.0.0 ISO를 선택해 cold boot합니다.
3. 구 ISO에서 만든 상태저장은 사용하지 않습니다.
4. 일반 메모리카드 저장을 불러옵니다.
5. 새 ISO에서 새 상태저장을 만듭니다.
