# Grandia III 한국어 패치 v0.1.4-test

`v0.1.3-test`를 대체하는 누적 시험 배포판이다. 새 런타임 증거에 따라 stream 0x63의
멀티슬롯 처리 경로를 보강했다. 깨끗한 원본에서 xdelta decode, 결과 SHA-256, 전체 byte 비교,
ISO9660/UDF 역추출을 검증했으며 relocation count는 `0`이다. 실제 게임 구동(runtime) 테스트는
추가 확인이 필요하다.

## 핵심 수정

- 알피나 방 stream 0x63 request `0x0414`를 slot0/slot1 양쪽에서 감시하고 하나의 lookup을 공유
- 미란다 기상 장면 stream 0x54의 slot1 자막 트리거 유지
- 충돌이 확인된 stream 0x62는 runtime 안전을 위해 계속 제외
- 비올레타·코넬 전투 전 0x9B 자막은 embedded sidecar 경로로 유지
- 기존 전투 글리프, 튜토리얼 도움말, 몬스터명 자연화, GRM13 30큐 분할 및 누적 번역 유지

## 적용 후 첫 실행 주의사항

상태저장 호환 문제를 피하려면 다음 순서로 실행한다.

1. PCSX2를 완전히 종료한다.
2. 새 ISO로 cold boot한다.
3. 구 ISO에서 만든 상태저장은 사용하지 않는다.
4. 일반 메모리카드 저장을 불러온다.
5. 새 ISO에서 새 상태저장을 생성한다.

- relocation count: `0`
- runtime test: pending

## 저작권 및 면책

Grandia III 관련 권리는 각 권리자에게 있다. 이 프로젝트는 비공식 팬 번역·연구 프로젝트이며
권리자와 제휴하거나 승인을 받은 프로젝트가 아니다. 원본 게임 ISO, 패치된 ISO, 추출된 영상·음성·
이미지·게임 리소스는 제공하지 않으며, 사용자는 자신이 합법적으로 보유한 원본에만 패치를 적용해야
한다. 개인적·비상업적 연구 목적의 배포이며, 사용으로 인한 데이터 손실이나 호환성 문제를 보증하지 않는다.
