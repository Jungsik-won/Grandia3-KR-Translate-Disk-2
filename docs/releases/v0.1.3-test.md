# Grandia III 한국어 패치 v0.1.3-test

`v0.1.2-test`를 대체하는 누적 시험 배포판이다. 원본 ISO에서 xdelta를 재적용한 결과와
ISO9660/UDF 역추출 결과를 byte-exact로 검증했지만, 실제 게임 구동(runtime) 테스트는 아직 대기 중이다.

## 추가 반영 내용

- 미란다 기상 장면 stream 0x54의 실제 slot1 자막 트리거 반영
- 알피나 방 stream 0x63의 실제 slot0 자막 트리거 반영
- 충돌이 확인된 stream 0x62는 runtime 안전을 위해 계속 제외
- 비올레타·코넬 전투 전 0x9B 자막을 안전 sidecar 경로로 유지
- 전투 명령 `작전`·`방어`의 잘못된 글리프 인덱스 교정
- 첫 전투 튜토리얼 도움말 인덱스 복구(`EN074C.DAT` 원본 유지)
- 원래 레코드와 행동 주소를 보존한 몬스터명 자연화
- GRM13 자막을 실제 발화 단위 30큐로 재분할
- 기존 누적 한국어 번역·하드서브 영상·결과 화면 및 전투 텍스처 유지

## 배포 파일

원본 게임 ISO, 패치된 ISO, 추출 게임 자산은 배포하지 않는다. GitHub Release에는 다음 6개 파일만

## 저작권 및 면책

Grandia III 관련 권리는 각 권리자에게 있다. 이 프로젝트는 비공식 팬 번역·연구 프로젝트이며
권리자와 제휴하거나 승인을 받은 프로젝트가 아니다. 원본 게임 ISO, 패치된 ISO, 추출된 영상·음성·
이미지·게임 리소스는 제공하지 않으며, 사용자는 자신이 합법적으로 보유한 원본에만 패치를 적용해야
한다. 개인적·비상업적 연구 목적의 배포이며, 사용으로 인한 데이터 손실이나 호환성 문제를 보증하지 않는다.
