# Grandia III 한국어 패치 v0.1.6-test

`v0.1.5-test` 이후의 누적 시험 배포판입니다. 최신 렌더링 자막 이벤트를 통합했으며, CLEAN
원본에서 xdelta decode, 결과 SHA-256, 전체 byte 비교, ISO9660/UDF 역추출을 검증했습니다.
실제 게임 구동(runtime) 테스트는 추가 확인이 필요합니다.

## 이번 추가 반영

- 렌더링 자막 normal events 62개, cues 701개 반영
- 42개 event의 request-slot 안정화 및 dual-slot dispatch 반영
- stream 0xD5 request `0x059C` 교정
- stream 0x9B 사용자 통과 normal-tail direct 자막 9큐 반영
- 기존 v0.1.5 UI·전투 수정과 누적 한국어 번역 유지
- v0.1.6~v0.2.1 아이템 습득 실험은 포함하지 않음

## 적용 후 첫 실행 주의사항

상태저장 충돌을 피하려면 다음 순서로 실행합니다.

1. PCSX2를 완전히 종료합니다.
2. 새 ISO로 cold boot합니다.
3. 구 ISO에서 만든 상태저장은 사용하지 않습니다.
4. 일반 메모리카드 저장을 불러옵니다.
5. 새 ISO에서 새 상태저장을 생성합니다.

## 검증 상태

- CLEAN 원본에서 xdelta decode 완료
- 복원 ISO SHA-256 일치 및 전체 byte-exact 비교 통과
- ISO9660/UDF 역추출 결과 byte-exact
- relocation count: `0`
- runtime test: pending

## 저작권 및 면책

이 배포에는 원본 또는 패치된 ISO, 추출 영상·음성·이미지·게임 리소스가 포함되지 않습니다.
xdelta 차등 패치와 적용 스크립트·문서·checksum만 제공합니다. 사용자는 합법적으로 보유한
정확한 일본판 원본에만 적용해야 합니다. 본 프로젝트는 비공식·비상업적 팬 번역/연구 프로젝트이며
권리자와 제휴하거나 승인받은 프로젝트가 아닙니다.
