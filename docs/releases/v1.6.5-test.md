# Grandia III 한국어 패치 v1.6.5-test 후보

`v0.1.6-test`의 검증된 전체 디스크 배치를 기준으로 세 파일만 동시에 교체한
런타임 검증용 후보입니다. 패치된 ISO나 원본 게임 바이너리는 Git에 포함하지 않습니다.

## 이번 반영

- 공용 UI는 게임 원본 본색·보조색·알파값을 그대로 유지
- 한글 그림자 크기를 본문과 동일한 `1.0x`로 조정
- 색 그림자를 본문 오른쪽 2px, 아래 1px인 `(+2,+1)`에 배치
- 달빛 이벤트의 전반 `0x67`과 후반 `0xA1`을 독립 이벤트로 직접 등록
- 종료된 stale request slot을 dispatcher가 건너뛰도록 진행값 guard 추가
- 0x9B path gate를 52바이트로 압축해 frame cave `1536/1536` 범위 유지
- 상세 PINE 추출기 v2 추가: request slot 진행 틱, secondary/resolved ID,
  자막 타이머, 작업 큐 매칭 및 수동 JSON 저장

## 테스트

관련 단위 테스트 29개를 실행해 28개 통과, 1개 조건부 skip, 실패 0개를 확인했습니다.
Python 구문 검사와 세 교체 파일의 ISO 역추출 byte 비교도 통과했습니다.

## 실기 확인

1. PCSX2를 완전히 종료한 뒤 새 ISO로 cold boot합니다.
2. 이전 ISO의 상태저장을 사용하지 말고 메모리카드 저장을 불러옵니다.
3. 메뉴·저장 화면에서 `(+2,+1)` 색 그림자를 확인합니다.
4. 달빛 이벤트 전반과 후반 자막이 끊김 없이 각각 표시되는지 확인합니다.
5. 0x9B 코넬 장면과 기존 렌더링 자막의 회귀 여부를 확인합니다.
