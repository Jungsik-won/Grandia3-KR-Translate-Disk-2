# Grandia III 한국어 패치 v0.1.1-test

기존 `v0.1` 한글화 추출 작업 이후의 시험 배포판이다.

## 배포 내용

- 누적 한국어 텍스트 및 폰트 적용분
- 한국어 하드서브 영상 적용분
- 0x9B 비올레타·코넬 장면 자막 적용분
- P1WIN~P7WIN 결과 화면 텍스처 적용분
- `bt_parts00` 최신 사용자 텍스처 적용분

## 배포 방식

원본 게임 ISO, 패치된 ISO, 추출 게임 자산은 배포하지 않는다. GitHub Release에는 다음만
올린다.

- `Grandia3_KR_Disc1_Korean_b4f69d38_full.xdelta`
- `apply_in_place_ko.sh`
- `apply_in_place_ko.ps1`
- `README_ko.md` (한국어 안내서)
- `release-manifest.json`
- `SHA256SUMS.txt`

## 필수 원본

사용자는 합법적으로 보유한 정확한 일본판 Disc 1 ISO가 필요하다.

- 크기: `4,598,890,496`바이트
- SHA-256: `c588a7dada3bf7175bfe97b238b0ab4c77df6401a58d766829aec9d92f3596e8`

패치 적용 결과는 `5,757,884,416`바이트, SHA-256
`b4f69d384ca92bbaf02f1b4ba363eb4f42e0a41b5f67ff864b5ad163a2c5f955`여야 한다.

## 검증 결과

지정 원본에 xdelta3 3.2.0으로 패치를 재적용했고, 결과 SHA-256과 정본 ISO의 전체 byte 비교가
통과했다. 패치 자산 SHA-256은
`20f9f5b8bbf96631b123db3f1889074d3569d8d44c01192d84593765e780c437`이다.

## 저작권 및 면책

Grandia III 관련 권리는 각 권리자에게 있다. 이 프로젝트는 비공식 팬 번역·연구 프로젝트이며
권리자와 제휴하거나 승인을 받은 프로젝트가 아니다. 원본 게임 ISO는 제공하지 않으며, 사용자는
자신이 합법적으로 보유한 원본에만 패치를 적용해야 한다. 개인적·비상업적 연구 목적의 배포이며,
사용으로 인한 데이터 손실이나 호환성 문제를 보증하지 않는다.
