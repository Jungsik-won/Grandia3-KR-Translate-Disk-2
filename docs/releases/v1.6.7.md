# Grandia III 한국어 패치 v1.6.7 테스트

## 렌더링 자막 통합

- 카지노 로컬 이벤트 `0x71`, `0x72`의 런타임 통과 구성을 유지한다.
- `0x72`는 회전 요청 슬롯 `0x00213550`/`0x002135DC`에서 sample `0x436`을 찾고,
  완료 요청을 건너뛰며 request progress에 자막 타이머를 동기화한다.
- 일반 렌더링 이벤트 63개는 모두 두 안정 request slot에 등록한다.
- `0xC8`은 `DATA/00150100.MDZ`, samples `0x57E`/`0x57F`, trigger `0x57E`로 등록한다.

## GR3SUB 적재 수정

- 외부 컨테이너 적재 정책을 `RETRY_UNTIL_INTEGRITY_PASS`로 변경한다.
- 첫 적재가 실패해도 영구 latch하지 않고 integrity 검사를 통과할 때까지 16프레임 간격으로
  재시도한다.
- SLPM data cave는 4156/4160바이트, frame cave는 1512/1536바이트를 사용한다.
- 결함판 SLPM SHA-256 `104786d004a838002a68d38f206499ee2ea2aee163d601569238630589d71b57`는
  사용하지 않는다.
