# Grandia III 한국어 패치 v1.6.6

## 렌더링 자막 통합

- 전체 자막 이벤트: 64개
- 카지노 로컬 경로: 2개 (`0x71`, `0x72`)
- 비카지노 외부 경로: 62개(일반 61개 + 별도 `0x9B` 1개)
- 카지노 필드 `DATA/00008000.MDZ`, `DATA/01040902.MDZ`에서는 외부 동기 로더를 호출하지 않는다.
- `0x9B`는 음성 요청 `0x4AE`가 활성화된 뒤에만 외부 컨테이너를 로드한다.
- 카지노 미니게임 전환과 스킵은 실기 통과한 v1.6.5 로컬 엔진을 유지한다.

## 0x72 회전 슬롯 수정 후보

- `0x71`은 기존 active-display 트리거를 유지한다.
- `0x72`는 `DATA/01040902.MDZ` 로컬 패키지를 유지하면서 회전 요청 슬롯
  `0x00213550`/`0x002135DC`를 모두 검사해 sample `0x436`이 든 쪽을 사용한다.
- 요청 진행값 `0xFFFFFFFF`는 즉시 종료로 처리하고, 살아 있는 요청 진행값을 로컬 자막
  타이머에 동기화한다.
- 외부 `GR3SUB.BIN` 동기 로더는 카지노 필드에서 계속 호출하지 않는다.
- 후보 ISO:
  `build/v1.6.6-0072-dualslot-20260902/Grandia3_KR_Disc1_v1.6.6_0072_dualslot.iso`
- SHA-256: `f28af3f1c4bfc0f9b32c054a584098ede863db44dcfa00e49416b5d4c9ee20e1`
- 상태: 정적·역추출 검증 통과, `0x72` 양 슬롯 트리거 자막 출력 및 카지노 전환 런타임 통과.
