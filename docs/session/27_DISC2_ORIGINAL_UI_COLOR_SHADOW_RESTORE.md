# DISK2 공용 UI 원본 색상·그림자 복구

## 범위

- 입력은 `Grandia3_KR_Disc2_battle_overlay_help_fix_static_test.iso`다.
- 한글 글리프와 번역 문자열은 유지하고 `FIELD.BIN`의 공용 UI 렌더링 정책만 원본으로 복구한다.

## 변경

- 공용 UI 색상 팔레트 64개 스타일, 2,048바이트는 이미 CLEAN 원본과 byte-exact이므로 수정하지 않았다.
- `FIELD.BIN 0x5A17E` 한 바이트만 `00 → 60`으로 되돌렸다.
- 이 변경은 무조건 분기로 꺼 두었던 보조 레이어를 원본 조건 분기로 복구한다.
- 결과적으로 원본 주 색상과 원본 `(1,1)` 흰 외곽선/드롭섀도 처리를 사용한다.
- 한국어 문자열, 글리프, 포인터, Result 화면 및 기타 코드는 유지한다.

## 누적 보존

- 직전 DISK2 후보의 `작전/방어` 직접 인덱스 보정과 전투 도움말 인덱스 복구를 유지한다.
- `FIELD.BIN` 외 1,265개 ISO 파일은 직전 후보와 바이트 단위로 동일해야 한다.
- DISK2 전용 부팅 파일과 `GRM50`~`GRM69` 영상은 그대로 보존한다.

정적 검증 후 PCSX2를 완전히 종료하고 새 ISO를 콜드 부팅하여 필드·시스템·상태/장비·세이브/로드·전투 UI의 색상과 흰 그림자를 확인한다.
