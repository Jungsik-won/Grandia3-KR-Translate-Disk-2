# DISK2 — 최신 DISK1 공용 업데이트 동기화

## 비교 기준

- DISK2 입력: 원본 UI 색상·그림자 복구 후보 `545d3266...06df1`.
- DISK1 검증 기준: v1.6.7 0xC8 동기화·전투 팝업 후보 `9d1becc7...7304`.
- 초기 DISK2의 공용 입력이 된 DISK1 누적판과 v1.6.7을 전수 비교했을 때 변경 파일은 7개였다.
- `MOVIE/GRM13.MOV`는 DISK1 전용이며 DISK2에는 존재하지 않으므로 제외했다.

## 채택 파일

1. `BATTLE.BIN`
   - 기존 `작전/방어` 7바이트 보정을 유지한다.
   - 전투 중 작전 패널 복제 슬롯 12개를 direct-index 인코딩으로 보정한다.
   - `진수 터득`, `습득!!`, `비결 습득`, `광폭화!`, `도주성공`, `도주실패`, `오토캔슬!` 팝업 7개를 추가 보정한다.

2. `SYS/GR3.MDZ`
   - DISK1 v1.6.7의 최신 한글 번역·전투 UI·몬스터명 누적본을 그대로 채택한다.
   - 기존 전투 도움말 인덱스 복구를 포함한다.

3. `GR3SUB.BIN`
   - 일반 63개 이벤트 726큐와 direct sidecar 1개 9큐, 총 64개 이벤트/735개 렌더링 큐를 포함한다.
   - stream `0xC8`의 빠진 초반 대사 5큐와 request progress 기준 타이머 동기화를 포함한다.
   - ISO9660-only 설계를 유지한다.

4. `SLPM_659.77`
   - 원본 DISK1/DISK2 실행 파일이 byte-exact였던 공통 구조를 근거로 v1.6.7의 `SLPM_659.76` 바이트를 DISK2 부팅명에 적용한다.
   - 외부 컨테이너 적재 실패를 영구 latch하지 않고 16프레임 간격으로 integrity PASS까지 재시도하며 0xC8 request progress 동기화를 유지한다.
   - DISK1 카지노 UI helper로 점프하는 8바이트 훅만 원본 변환기 진입부로 복구한다. 나머지 v1.6.7 자막 엔진은 byte-exact 보존한다.

5. `DATA/01040902.MDZ`
   - stream `0x72` 로컬 자막 패키지와 회전 request slot 0/1 정책을 채택한다.

## 제외

- `MOVIE/GRM13.MOV`: DISK1 전용이며 DISK2에 없음.
- 최신 DISK1 `FIELD.BIN`: 팔레트 영역 내 카지노 helper와 `(+2,+1)` 스타일을 사용해 사용자가 선택한 원본 색상·`(1,1)` 그림자 정책과 충돌하므로 제외. DISK2의 `c6ec65d1...64146`을 유지한다.
- v016~v021 아이템 습득 실험: 런타임 실패로 폐기된 후보이므로 재사용 금지.

최종 검증은 교체 5개를 제외한 DISK2 파일 1,261개 byte-exact 보존, ISO9660/UDF 역추출, 원본 UI 스타일, DISK2 부팅 파일과 GRM50~GRM69 보존을 확인한다.
