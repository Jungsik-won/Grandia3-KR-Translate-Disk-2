# Disc 2 공용 번역 누락 감사

작성일: 2026-09-01  
대상: 일본판 Disc 2 원본과 현재 Disc 1 기반 공용 한국어 번역 자산

## 결론

현재 추출·구조화된 텍스트 범위에서는 Disc 2 전용 미번역 문장이 없다. Disc 2는
Disc 1 기준 공용 번역을 그대로 재사용한다. 감사 결과는 `PASS`이며 공용 DB와 CSV의
고유 ID는 각각 21,171건으로 정확히 일치하고, 미번역·미인코딩·일본어 잔존 행은 0건이다.

단, 이 결론은 알려진 구조화 텍스트 모집단에 대한 것이다. 실제 플레이 중 새 런타임
문장이 확인되면 Disc 2 전용 파일에만 임시로 넣지 않고, 공용 기준본에 새 stable ID로
추가한 뒤 Disc 1과 Disc 2 빌드가 함께 소비하도록 한다.

## Disc 1 번역을 그대로 재사용할 수 있는 근거

- 두 디스크의 공통 경로는 1,244개이고 1,241개가 SHA-256까지 동일하다.
- `BTL` 442/442, `DATA` 393/393, `MUSIC` 387/387 파일이 모두 바이트 동일하다.
- `SYS`는 9개 중 8개가 동일하고 `SYS/SYSWIN0.MDZ`만 다르다.
- Disc 2 시나리오 5,903건은 공용 `SCN_*` 기준본 5,903건과 stable ID, 원문 바이트,
  파일·레코드·오프셋 구조가 전부 대응한다.
- 공중 이동 고정문 3건과 랜드마크 안내 4건도 모두 번역 완료 상태이며 해당 소스는
  두 디스크에서 동일하다.

공통 파일 중 실제 차이는 `SYSTEM.CNF`, `SYSTEM.INI`, `SYS/SYSWIN0.MDZ` 세 개뿐이다.
앞의 두 파일은 부트 디스크 번호 차이이고, `SYSWIN0.MDZ`는 Disc 2 원본 컨테이너를
기준으로 한국어 UI 리소스만 병합해야 한다. Disc 1 파일을 통째로 복사하면 안 된다.

## 이번 감사에서 보완한 공용 기준본

Disc 2 전용 신규 문장은 없었지만, 최근 런타임 검증 결과가 CSV에는 반영되고
`translation.db`에는 아직 반영되지 않은 6건을 발견했다. 검증된 CSV 값을 공용 DB로
동기화했다.

| ID | 공용 확정 내용 |
|---|---|
| `ENEMY_ACTION_0036` | `アノード` → `양극` |
| `ENEMY_ACTION_0037` | `ダークフィスト` → `암흑권` |
| `SCN_00216000_00740000_0016` | `비행하기 / 그만두기`와 고정 13바이트 보존 근거 |
| `SCN_00216000_00740000_0017` | `비행하기 / 다른 장소로 간다 / 그만두기`와 고정 25바이트 보존 근거 |
| `SKILL_0021_NAME` | `影法師` → `그림자분신` |
| `SKILL_0021_DESC` | `실체화한 분신이 함께 공격한다`와 해독된 원문 토큰 |

동기화 전 DB는
`backup/translation_20260901_before_disc2_common_sync.db`에 보존했다. 동기화 후
완료 감사와 Disc 2 공용 감사를 다시 실행했고 모두 `PASS`했다.

## 원본 전체 휴리스틱 스캔 판정

기존 구조화 추출기 밖의 문자열을 찾기 위해 Disc 2의 MDZ 399개, 해제 데이터
2,011,946,624바이트를 두 방식으로 전수 스캔했다.

- 엄격한 Shift-JIS 스캔: 3,274개 후보, 1,309개 고유 문자열
- 게임 전용 문자표 스캔: 46,430개 군집, 192,057개 후보

이 수치는 번역 행 수가 아니다. 모델·텍스처·압축 데이터의 임의 바이트도 문자표에
걸리므로 대부분 이진 오탐이다. 읽을 수 있는 일부 항목도 환경 맵 이름과 사운드 라이브러리
오류문 같은 개발용 내부 문자열이었다. 공용 `DATA`에서 나온 후보는 Disc 1과 원본 바이트가
동일하므로 Disc 2 신규 텍스트가 아니다.

유일하게 다른 `SYSWIN0.MDZ`에서 전용 문자표 후보는 1개뿐이었고, 의미 없는 문자열로
판정되어 번역 DB에 올리지 않았다. 휴리스틱 후보는 자동으로 번역 행으로 승격하지 않는다.

## Disc 2에 남은 별도 작업

1. `GRM50.MOV`는 Disc 1 `GRM01.MOV`와 동일하므로 기존 결과를 재사용한다.
2. `GRM51.MOV`부터 `GRM69.MOV`까지 19개는 Disc 2 신규 영상 번역·자막 대상이다.
3. `SYS/SYSWIN0.MDZ`는 Disc 2 원본 보존형 한국어 리소스 병합이 필요하다.
4. 완성 ISO에서 Disc 2 진행 전 구간을 플레이해 런타임에서만 드러나는 문장을 확인한다.
5. 새 문장이 발견되면 공용 CSV/DB에 먼저 보완하고 두 디스크 빌드에 함께 연결한다.
