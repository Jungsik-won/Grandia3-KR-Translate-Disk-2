# DISK2 전투 UI 작전/방어 표시 수정 반영

## 반영 기준

- 입력 ISO: `Grandia3_KR_Disc2_common_korean_static_test.iso`
- 참조 작업에서 정적 검증을 통과한 `BATTLE.BIN`과 `SYS/GR3.MDZ`만 누적했다.
- 이후 만들어진 적명, 자막 등 다른 작업 산출물은 이번 범위에 포함하지 않았다.

## 수정 내용

1. `BATTLE.BIN`
   - 전투 UI의 `작전` 1개 슬롯과 `방어` 2개 슬롯을 직접 인덱스 렌더러용 인코딩으로 보정했다.
   - 변경은 지정된 7바이트뿐이며 폰트, 텍스처, 포인터, 코드는 바꾸지 않았다.
   - 대상 오프셋: `0x90D58`, `0x90D5A`, `0x90DB0`, `0x90DB2`, `0x90DB3`, `0x93C50`, `0x93C52`.

2. `SYS/GR3.MDZ`
   - 제거된 추가 전투 도움말 풀을 가리키던 잘못된 인덱스를 원래 고정 레코드 구조로 복구했다.
   - 전투 도움말 64개 레코드의 고정 오프셋과 크기를 유지했다.
   - 변경 범위 밖 폰트, 텍스처, 기타 GR3 영역은 그대로다.

## 보존 및 검증

- ISO9660/UDF 양쪽에서 두 파일의 동일 위치·동일 크기 교체를 역검증한다.
- 나머지 1,264개 파일은 직전 DISK2 한글화 후보와 바이트 단위로 동일해야 한다.
- DISK2의 `SYSTEM.CNF`, `SYSTEM.INI`, `SLPM_659.77`, `SYS/SYSWIN0.MDZ`, `GRM50`~`GRM69`은 보존한다.
- 원본 ISO는 수정하지 않는다.

정적 검증 통과 후에도 실제 판정은 PCSX2 완전 종료 뒤 새 ISO를 콜드 부팅하여 `작전`, `방어` 선택 시 작은 일본어 모양 글자, 전투 도움말 표시를 확인해야 한다.
