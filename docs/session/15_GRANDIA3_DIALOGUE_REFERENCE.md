# GRANDIA III 대사 한글화 참고 인덱스

> 작성일: 2026-08-22  
> 목적: PS2 일본판 **그란디아 III (グランディアIII)** 한글화 작업에서 추출한 일본어 문자열을
> **화자 / 장면 / 진행 순서 / 선택 대화 유형**에 맞춰 식별하기 위한 참고 문서.
>
> **중요:** 이 문서는 공개된 타인의 대사집을 그대로 복제한 “전체 대사집”이 아니다.
> 저작권이 있는 게임 스크립트 전문은 수록하지 않고, 공개 자료의 **위치·용도·매칭 방법**을 정리한다.

---

## 1. 결론부터

현재 웹에서 확인 가능한 범위에서는 **일본어판 전체 대사를 한 곳에 완전하게 전사한 자료는 찾지 못했다.**

대신 다음 자료를 조합하면 한글화용 대사 식별 자료로 상당히 강력하다.

1. **영문판 전체 Game Script**
   - 메인 이벤트의 장면 순서와 화자 파악용.
2. **일본 플레이 일지**
   - 실제 일본어판 화면과 일부 대사의 원문 확인용.
3. **일본 GRANDIA3攻略@wiki의 DISC1/DISC2 차트**
   - NPC 대사 변화, 식사 이벤트, 비행 중 무선, 서브 이벤트 발생 시점 파악용.
4. **Battle Quotes FAQ / Battle FAQ**
   - 전투 중 캐릭터 음성의 종류와 캐릭터별 분류용.
5. **일본 스토리 요약 Wiki**
   - 장면 위치를 빠르게 찾는 보조 자료.

따라서 일본판에서 추출한 텍스트를 기준으로 작업하고, 영문 스크립트는
**“번역 원문”이 아니라 화자·장면을 찾기 위한 인덱스**로 사용하는 것이 가장 안전하다.

# 2. 최우선 자료

## A. 영문 전체 스크립트 — Grandia III Game Script

- 작성자: OKong / Oliver Kong
- 업데이트: 2006-06-07
- 형식: 게임 진행 순서대로 장면 설명 + 화자별 영문 대사
- 가장 좋은 용도:
  - 추출 문자열의 **화자 추정**
  - 대사의 **앞뒤 순서**
  - 이벤트가 어느 장면인지 확인
  - 메인 시나리오 블록 분할
- 주의:
  - 일본어 원문이 아니라 **북미판 현지화 대사**다.
  - 일본판과 어순, 표현, 문장 수가 1:1로 일치하지 않을 수 있다.
  - NPC 선택 대사나 일부 부가 대화가 모두 들어 있다고 보장할 수 없다.

URL:
https://www.neoseeker.com/grandia-iii/faqs/130442-script.html

### 실전 사용법

일본어 덤프에서 특징적인 고유명사나 의미를 잡은 뒤 영문 스크립트에서 해당 장면을 찾는다.

예:

```text
[일본판 추출 문자열]
        ↓
고유명사 / 상황 / 앞뒤 문자열 확인
        ↓
영문 Game Script에서 장면 후보 검색
        ↓
화자 + 스토리 시점 확정
        ↓
일본판 플레이 영상/일지로 최종 검증
```

# 3. 일본어판 진행 / NPC 대화 인덱스

## GRANDIA3攻略@wiki

메인:
https://w.atwiki.jp/grandia3/

### DISC1 상세 차트

https://w.atwiki.jp/grandia3/pages/38.html

공략 사이트 자체가 다음과 같은 점을 강조한다.

- NPC가 각자 작은 이야기를 가지고 있음.
- 이벤트 진행에 따라 대화가 바뀜.
- 사람에게 여러 번 말을 걸면 대사가 바뀌는 경우가 있음.
- 특정 시점에 이전 지역으로 돌아가면 주민 대사가 변경됨.
- 비행 중 무선 대화가 존재함.
- 숙박 시 식사 이벤트가 존재함.

### DISC1의 큰 구간

1. 오프닝 ~ 안포그 숲
2. 안포그 마을 ~ 사바타르 해안
3. 사바타르 항구 ~ 란도토 섬
4. 멘디
5. 아크리프 숲 ~ 아크리프 신전
6. 란도토 섬 2
7. 비행기로 들르는 이전 지역
8. 비룡의 계곡
9. 바크라 집락
10. 바크란 사막

### 특히 놓치기 쉬운 대화

#### 조사 대사

초반 차고에서 다음과 같은 오브젝트를 조사할 수 있다고 기록되어 있다.

- 신문
- 설계도
- 비행기
- 날개
- 충전기
- 엔진
- 프로펠러
- 사다리

즉 시나리오 대사와 별개로 **오브젝트 조사 문자열**이 상당히 있을 가능성이 있다.

#### 반복 NPC 대화

공략에는 사람에게 여러 번 말을 걸면 내용이 변화한다고 명시되어 있다.

덤프에서 비슷한 문장이 연속으로 여러 개 발견될 경우 삭제하거나 중복으로 보지 말고
**동일 NPC의 반복 회화 단계**일 가능성을 먼저 의심한다.

#### 식사 이벤트

멘디를 비롯해 숙박 시 식사 이벤트가 존재한다.

따라서 대사 덤프 분류에 아래 태그를 별도로 두는 것을 권장한다.

```text
MEAL_EVENT
```

#### 비행 중 무선

자유 비행 가능 시점에는 다음과 같은 무선 회화가 발생한다고 기록되어 있다.

- 상공에서의 말다툼
- 관제관 관련 대화
- 날씨 안내
- 기타 비행 중 잡담

따라서 메인 이벤트에서 찾히지 않는 음성/대사 중 일부는 다음 계열일 수 있다.

```text
FLIGHT_RADIO
```


즉 특정 메인 이벤트가 끝날 때마다 기존 마을 NPC의 대사가 새 세트로 교체되는 구조다.

### 후반부 역방문

후반에는 지상으로 돌아가면 여러 마을의 대사가 다시 변화한다.

특히 다음 지역의 역방문 대사를 별도 블록으로 잡는 것이 좋다.

- 안포그
- 사바타르
- 멘디
- 바크라
- 비룡의 계곡
- 라프리드

일부 대화에는 그 시점의 동료인 **헥트가 참여**한다고 공략에 명시되어 있으므로,
메인 스토리 스크립트만 기준으로 잡으면 빠질 가능성이 높다.

## 이름 주의사항

영문판은 일본판과 **고유명사가 현지화되어 다른 경우가 있다.**

예를 들어 일본 자료에서 보이는 `デュンケル`과 영문 자료의 인명 표기가
항상 문자 그대로 대응하지 않을 수 있다.

따라서 고유명사는 다음 우선순위로 확정한다.

```text
일본판 게임 내 표기
    >
일본 공식/공략 자료
    >
일본 플레이 일지
    >
영문 현지화판
```

# 8. 권장 대사 ID 체계

대사를 단순 번호만으로 관리하지 말고 **DISC + 장면 + 종류**를 ID에 넣는 것이 좋다.

예:

```text
D1-ANFOG-MAIN-0001
D1-ANFOG-NPC-0001
D1-MENDI-MEAL-0001
D1-FLIGHT-RADIO-0001

D2-TERRARIUM-MAIN-0001
D2-TERRARIUM-NPC-0001
D2-SURMANIA-MAIN-0001
D2-RAFLID-NPC-0001
```

### 추천 종류

| 태그 | 의미 |
|---|---|
| MAIN | 메인 시나리오 |
| NPC | 일반 NPC 대화 |
| NPC_REPEAT | 같은 NPC 반복 대화 |
| SUB | 서브 이벤트 |
| MEAL | 숙박 / 식사 이벤트 |
| RADIO | 비행 중 무선 |
| INSPECT | 물건 조사 |
| BATTLE | 전투 음성 |
| TUTORIAL | 전투 / 시스템 튜토리얼 |
| SYSTEM | 시스템 메시지 |
| UNKNOWN | 아직 미분류 |

# 9. 추출 대사 관리용 표준 레코드

실제 한글화 파일에는 최소한 아래 정도를 남기는 것을 권장한다.

```markdown
### D1-XXXX-MAIN-0001

- Source file:
- Offset / Address:
- JP:
- Speaker:
- Scene:
- Previous:
- Next:
- EN anchor:
- KR:
- Confidence:
- Notes:
```

### Confidence 권장값

```text
A = 일본판 화면/음성까지 확인
B = 일본 플레이 일지 또는 영상으로 확인
C = 영문 스크립트와 장면 일치
D = 문맥 추정
? = 미확인
```

# 10. GR3.MDT 등에서 대사가 추출되었을 때의 매칭 순서

```text
1. 일본어 문자열 추출
2. 고유명사 / 어미 / 말투로 화자 후보 추정
3. 앞뒤 문자열을 함께 확인
4. DISC1 / DISC2 공략 차트에서 해당 이벤트 시점 후보 선정
5. 영문 전체 스크립트에서 의미상 일치하는 장면 검색
6. 일본 플레이 일지에 같은 장면이 있는지 확인
7. 필요하면 실제 게임/영상으로 최종 확인
8. Speaker / Scene / ID 확정
9. 한국어 번역
```

### 절대로 바로 번역부터 하지 않는 것이 좋은 문자열

- 한두 단어짜리 짧은 대사
- `はい / ええ / そう / なんだ / でも` 같은 문맥 의존 표현
- 고유명사가 없는 독백
- 동일 문장이 여러 번 반복되는 문자열
- NPC의 인사말
- 이벤트 선택지
- 조사 메시지

이런 문자열은 **앞뒤 블록과 장면을 먼저 잡은 뒤 번역**하는 것이 안전하다.

# 11. 영문 스크립트와 일본판을 맞출 때 주의할 점

영문판은 번역 과정에서 다음 변화가 있을 수 있다.

- 한 문장이 두 문장으로 분리
- 두 문장이 한 문장으로 합쳐짐
- 주어 추가
- 이름을 직접 부르는 표현 추가/삭제
- 일본어의 생략된 목적어 보충
- 말투 변경
- 농담/관용구 현지화
- 장면 의미는 같지만 문장 자체는 크게 변경

따라서 다음 식으로 **의미 단위**로 맞춘다.

```text
JP 3줄 = EN 2줄
JP 1줄 = EN 2줄
```

도 정상적인 상황으로 취급한다.

# 12. NPC 대사를 따로 관리해야 하는 이유

GRANDIA3攻略@wiki는 이 게임의 NPC가 이벤트 진행에 따라 각자의 이야기를 이어 간다고
명시하고 있으며 실제 DISC 차트에도 수시로 `村人の会話が変化`가 등장한다.

따라서 한글화 완성도를 높이려면 메인 시나리오만 번역해서는 부족하다.

추천 분리:

```text
scenario_main/
scenario_optional/
npc/
meal/
flight_radio/
inspect/
battle_voice/
system/
```

특히 나중에 **“번역 누락 찾기”**를 할 때 이 구조가 유리하다.

# 13. 우선순위

현재 작업 목적을 기준으로 추천 순서는 다음과 같다.

## 1순위 — MAIN

메인 이벤트 대사.

- 영문 전체 스크립트와 가장 쉽게 매칭 가능.

## 2순위 — NPC

마을 대화.

- 공략 위키의 대화 변경 시점을 기준으로 블록화.
- 같은 NPC의 여러 단계 대사를 보존.

## 3순위 — MEAL / RADIO / SUB

놓치기 쉬운 선택 이벤트.

- 식사
- 자유 비행 무선
- 탐정 서브 이벤트
- 역방문 대화

## 4순위 — BATTLE

전투 음성.

- Battle Quotes FAQ로 종류 분류.
- 일본 음성은 실제 게임에서 별도 검증.

## 메모

현재 가장 큰 수확은 **일본 공략 위키가 단순 공략뿐 아니라 NPC 회화 변화 시점을
DISC1/DISC2 전체에 걸쳐 기록하고 있다는 점**이다.

따라서 게임 데이터에서 시나리오 문자열 덩어리를 찾은 뒤,
단순히 “메인 시나리오 전체 대사”로 취급하지 말고 다음처럼 분리해서 보는 것이 좋다.

```text
메인 이벤트
+ 일반 NPC
+ 이벤트 진행별 NPC 변형
+ 식사 이벤트
+ 비행 무선
+ 서브 이벤트
+ 조사 대사
+ 전투 음성
```

이 구조를 유지하면 이후 일본어 원문 덤프가 확보되었을 때
`JP → 화자 → 장면 → EN anchor → KR` 순으로 반자동 매칭 테이블을 만들기 쉬워진다.
